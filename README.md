## 🚀 Projetos

### 🔎 [Port Scanner em Python](https://github.com/devmatheuscode/port-scanner-python)
Scanner de portas TCP escrito do zero com a biblioteca `socket`, evoluindo em 3 versões:

- ⚡ Varredura de faixas de portas com **multithreading** (`ThreadPoolExecutor`, 100 threads) e medição do tempo total.
- 🏷️ **Banner grabbing** para identificar o serviço rodando em cada porta (HTTP, FTP, SSH, SMTP…).
- 🌐 **API em Flask** com interface web para disparar varreduras e salvar os resultados.

### 🛡️ CYMAG Enterprise — Plataforma de testes de segurança automatizados
*Projeto Integrador · SENAI · 2026*

- 🔎 Auditoria **blackbox** em rede de laboratório (SIMOC Cyber Range) com **6 vulnerabilidades críticas** identificadas e documentadas — SQL Injection, Node-RED sem autenticação, MQTT sem TLS e SMB Signing desabilitado.
- ⚙️ Varredura de rede automatizada em **Python**, orquestrando **Nmap, SQLMap e CrackMapExec** em um único fluxo.
- 🤖 **IA generativa (Llama 3)** transformando saídas técnicas em relatórios executivos com severidade **CVSS v3.1**.
- 📊 **Dashboard em Flask** com score de risco consolidado e exportação de relatório em PDF.
